# Petri Dish

**Petri Dish** — это симуляционная среда, предназначенная для тестирования и визуализации поведения агентов (например, дронов, бактерий, частиц и т.п.) в ограниченной 2D-среде. Проект разработан для моделирования автономного поведения, взаимодействия агентов и отладки алгоритмов навигации или распространения.

## Основные возможности

- ✅ Симуляция агентов в двумерной замкнутой среде
- ✅ Визуализация поведения в реальном времени
- ✅ Гибкая настройка параметров: количество агентов, скорость, правила столкновений
- ✅ Возможность интеграции с алгоритмами AI/ML для управления агентами
- ✅ Поддержка логирования и экспорта результатов
